# CQI at STAR

Plain-language CQI support resources for STAR Site Directors, Cluster Leads, and other STAR staff.

This website is maintained by **Karen Crozer, STAR Development Office** as a STAR support resource. It is **not an official Beyond the Bell website or resource**. Official forms, directions, and required submissions should be completed through current BTB materials, official BTB forms, and the BTB Portal.


Includes a SMART Goal & Action Step Help page with public-facing sample goals, common revisions, action-step examples, and a 12-question browser-based practice activity for the 2026–27 STAR Point-of-Service Action Plan. The practice does not save or send answers.
